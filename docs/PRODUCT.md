# Produit

Le site rassemble des projets personnels et quelques informations sur Mathis.
Il exprime le plaisir de créer, la curiosité et les intérêts techniques.
Éviter les promesses de prestation, les métriques inventées, le vocabulaire
de vente et le ton de candidature.

## Navigation

Accueil, Projets, À propos, Contact. Trois fiches publiques : SpellWar,
The Algorithmic Beauty of Plants, Eyefox Puzzle. Le filtre sépare jeux et
génératif. Skull reste un brouillon non affiché.

Le français est la langue de base ; l’anglais est disponible sous `/en/`.
Le changement de langue conserve la page visitée. Pas de détection serveur
de langue nécessaire sur l’hébergement statique.

Le thème suit le navigateur par défaut. Le bouton alterne uniquement entre clair et sombre et mémorise le choix manuel.
Les liens externes et la copie du profil GitHub fonctionnent sans compte.
Sonner confirme la copie et indique son éventuel échec.

## Contenu

Le diplôme et le rôle actuel proviennent des réponses de Mathis.
Les descriptions de projets restent fondées sur leurs README publics.
Les textes FR/EN seront revus lors du questionnaire final.
Le second compte GitHub n’est ni affiché ni lié sur le nouveau site.

Aucun formulaire de contact, service d’authentification, tracking ou backend
n’est ajouté. Le CV est transmis séparément par Mathis.
